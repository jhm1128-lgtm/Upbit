# v1.8.1 화면 수정 검토 — 2026-10-30

사용자 요청에 따라 밝은 청회색, 주요 버튼 강조, 큰 시장 상태 표시, 보유/손익 약 5행, 상단 후보/차트 확대, 후보 전용 메뉴 제거, 최소화/X 트레이를 반영했다.

## 표시 결함 수정
기존 `상승 추세 14/14 (7.1%)`의 앞 숫자는 유효 자료 수/예상 후보 수였다. 상승 수가 14라는 뜻이 아니며 비율과 혼동되는 표기였다. 이제 `분석 가능 14/14 · 상승 1/14 (7.1%)`로 별도 표시한다. 시장 판단이 무효화되면 예전 비율을 계속 보여주지 않는다. 시장 조건·비율 경계값은 유지했다.

표시 이름: 내부 normal→BULL(정상 진입), cautious→NORMAL(중립/주의·축소), bear→BEAR, unknown→WAIT, recovering→RECOVERING. 이 명칭은 화면/트레이 표시이며 전체 시장의 장기 방향이나 수익 예측이 아니다.

## 검증
- 기존 시험 포함 62개 모의·GUI·통합 시험 통과.
- 실제 Tk 최소화 이벤트 이후 withdrawn, 트레이 창 열기 요청 후 normal 복원 확인. 이 별도 시험은 모의 트레이 등록 상태로 창 이벤트를 검증했다. 원래 네이티브 트레이 등록/제거 시험은 v1.8 때 완료했다.
- 1536×1000 합성 데이터 미리보기에서 후보 표 220px, 보유 표 167px 확인. 보유 표는 데이터 5행을 요청하고 남는 높이는 상단이 사용한다. DPI/창 크기에 따라 실제 가시 행은 달라질 수 있다.
- 밝은 색·표·차트·시장 상태의 실제 렌더를 확인했다. [미리보기](preview.png)는 별도 임시 원장의 합성 데이터로 실제 계좌/현재 시세가 아니다.
- 누적 수수료 음수 제안은 사용자가 철회했다. 양수 합계를 유지하고 실현손익을 재차 차감하지 않는다.
- 최대보유 5종목은 이번 UI 패치에서 적용하지 않았다. 15만원×3=45만원과 ×5=75만원의 노출 차이를 설명하고 고정 설정 검증 이후의 비교 후보로 남겼다.

v1.8 관찰을 이어가며, DB·설정·비교 원장을 초기화하지 않는다. 운영 적용은 프로그램 중지·완전 종료 후 사용자가 업데이트 ZIP을 적용하는 단계다. 계좌 키·운영 DB·원본 기록은 이 저장소에 포함하지 않는다.
