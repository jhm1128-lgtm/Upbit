# v1.8.2 조회 화면 검토

사용자 요청: 가상 보유 메뉴 통합, 누적 로그, 거래 수익률, 열 자동 맞춤, 명확한 종목 필터와 연/월 이동 달력.

## 완료한 동작
- 가상 보유와 후보 조회는 대시보드에서 확인. 숨긴 전용 메뉴 인덱스 접근도 대시보드로 이동하며 다른 메뉴는 유지.
- 거래내역에 순수익률을 추가하고 CSV에도 파생 열로 기록. 매도 수량의 배분 매수원가+매수 수수료 대비 순실현손익이며 원본 금액은 변경하지 않음.
- 열 제목 경계 더블클릭 자동 폭 조절, 전체 열 맞춤 버튼.
- 거래 기록의 종목 목록과 XRP/KRW-XRP 정확 일치, KST 양끝 날짜 포함과 필터 요약.
- 클릭 달력, 월/연 화살표 및 키보드 이동, 날짜 선택/오늘/취소.
- DB의 전체 누적 로그에 대해 검색·종류·기간 필터와 200개씩 조회. 과거 페이지를 읽을 때 위치 유지.

## 확인
76개 모의·GUI·통합 시험 통과. 달력 선택일 강조 후 해당 GUI 시험 재확인. 과거 매도 171건의 수익률을 읽기 전용 사본에서 독립 대조해 차이 0 확인. [거래내역](v182_history.png), [달력](v182_calendar.png), [누적 로그](v182_logs.png)는 별도 임시 원장의 합성 데이터 화면임.

원장 계산·매매 정책·최대 보유 3·실거래 잠금·비교 원장 유지. 업데이트 중 중단 시간만 구분하며 기존 관찰 구간을 초기화하지 않음. 원본 운영 DB·키·설정은 저장소에 포함하지 않음.
