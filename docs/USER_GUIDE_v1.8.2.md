# v1.8.2 — 거래 수익률 · 종목/달력 조회 · 누적 로그

2026-10-30 제작한 조회 화면 수정판입니다. v1.8/v1.8.1의 매매 정책·주문 설정·원장·기존 비교 관찰을 이어갑니다.

## 업데이트
1. 프로그램에서 중지를 누르고 감시 종료를 기다립니다.
2. 트레이 우클릭 → 프로그램 종료로 완전히 종료합니다. X는 숨김입니다.
3. validation.sqlite3, benchmark_v18.sqlite3, settings.json을 백업합니다.
4. Upbit_v1.8.2_UI_Update.zip 안의 파일을 C:\UpbitAutoTrading에 바로 풀고 덮어씁니다.
5. 기존 아이콘으로 실행해 v1.8.2를 확인하고 시작합니다. v1.7은 먼저 v1.8로 업데이트해야 합니다.

업데이트 ZIP에는 운영 DB·설정·키·CSV를 넣지 않습니다. 새 설치는 Full ZIP을 사용합니다. 기존 약 1주일 관찰을 초기화하지 않고 업데이트 중 중단 시간만 구분합니다.

## 메뉴와 보유
가상 보유 전용 메뉴를 제거하고 메인 대시보드의 보유 표로 통합했습니다. 보유가 없어도 표가 표시되며 기존 손절·익절 감시는 유지합니다. 이전에 제거한 매수후보 전용 메뉴도 다시 추가하지 않았습니다. 대시보드·거래내역·가상손익·전략설정·로그·가상기록을 사용합니다.

## 거래내역 수익률
실현손익 바로 옆에 수익률(%)을 표시합니다. 매수는 실현 수익률이 없으므로 —입니다.

매도 수익률은 **해당 매도 수량에 대응하는 매수금액+배분 매수 수수료**를 분모로, 수수료를 반영한 실현손익을 나눈 값입니다. 매도 수수료도 실현손익에 반영됩니다. 부분익절/잔여 매도 각각의 수익률이며 전체 포지션 합산 수익률과 다를 수 있습니다. 기존 실현손익에서 수수료를 다시 빼지 않습니다.

paper_trades.csv와 검토 ZIP의 같은 CSV에도 return_pct 열을 추가했습니다. 원본 거래 DB의 금액과 체결 이벤트는 변경하지 않습니다. 매수 또는 원가를 계산할 수 없는 기록은 빈 값입니다.

## 열 너비
표의 **열 제목 사이 경계를 더블클릭**하면 해당 열이 현재 화면에 적재된 내용과 제목에 맞춰 줄거나 늘어납니다. 지나치게 긴 내용은 최대 폭 안에서 맞추며 가로 스크롤을 사용할 수 있습니다. 거래내역 상단의 '열 너비 자동 맞춤'은 현재 표의 모든 열에 적용합니다. 손으로 끌어 조절하는 기능도 유지합니다. 표 안의 거래 행 더블클릭과 구분하세요.

## 종목과 기간 조회
- 종목 목록에는 실제 가상 거래 기록에 있는 코드가 나옵니다. 목록에서 선택하거나 XRP, KRW-XRP처럼 입력하고 Enter/조회 버튼을 누릅니다.
- 종목은 정확히 일치시킵니다. XRP로 조회하면 KRW-XRP만 나오며 비슷한 다른 코드가 섞이지 않습니다. '전체' 또는 빈 입력은 모든 종목입니다. 없는 코드면 0건으로 표시합니다.
- 시작일/종료일의 날짜 칸이나 '달력' 버튼을 누르면 달력이 열립니다. 월 ◀/▶와 연 ◀/▶ 버튼, 키보드 ←/→(월), ↑/↓(연)로 이동한 뒤 날짜를 누릅니다. '오늘'로 오늘 날짜도 선택할 수 있습니다. Escape/X는 취소입니다.
- 날짜는 KST 기준이며 시작일·종료일을 모두 포함합니다. 비어 있는 경계는 제한하지 않습니다. 시작일이 종료일보다 늦으면 안내하고 조회하지 않습니다.
- '기간 지우기'는 날짜만 지우고 종목/유형은 유지합니다. '전체 보기'는 모든 필터를 초기화합니다. 요약에 현재 종목과 조회 기간을 명시합니다.

## 누적 로그
로그 메뉴는 SQLite에 저장된 이전 실행 기록까지 조회하는 화면으로 바꿨습니다. 종류·내용·기간으로 검색하고 최신순으로 200개씩 봅니다. '이전 기록 ▶'으로 과거 전체 기록을 계속 조회하고 '◀ 최신 쪽'으로 돌아갑니다. 원본 로그를 삭제하지 않습니다.

최신 페이지는 로그 메뉴를 보는 동안 약 5초 간격으로 갱신하고 오래된 페이지는 읽는 위치를 유지합니다. '조회/최신'은 첫 페이지로 이동합니다. 대시보드의 짧은 실시간 로그와 구분됩니다. 통신·시장 상태의 별도 구조화 기록은 기존 검토용 ZIP으로 내보냅니다.
