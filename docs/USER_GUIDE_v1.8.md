# 업비트 v1.8 — 약세장 보호 · 급변 방어 · 비트코인 트레이

가상매매 검증용 업데이트입니다. 목표는 약세 구간의 노출을 줄이고 추세가 회복된 구간의 기회를 유지하는 것입니다. 손익 개선과 실거래 안전성이 검증된 버전은 아닙니다.

## 기존 v1.7에 적용
1. 프로그램 중지 후 감시 종료를 기다리고 창을 완전히 종료합니다.
2. C:\UpbitAutoTrading\validation.sqlite3와 settings.json을 백업합니다. v1.8 재업데이트 때에는 benchmark_v18.sqlite3도 백업합니다.
3. Upbit_v1.8_BearGuard_Update.zip 안의 파일을 C:\UpbitAutoTrading에 바로 풀고 덮어씁니다. 하위 폴더 안에 넣지 마세요.
4. 기존 바탕화면 아이콘으로 실행하고 v1.8 및 시장 상태 줄을 확인한 뒤 시작합니다.
5. 별도로 바로가기 아이콘을 설정하려면 아이콘_설정.bat을 실행합니다.

업데이트 ZIP에는 DB·설정·CSV·API 키를 넣지 않습니다. 기존 잔고·보유·거래·매매 설정·당일 재매수 제한은 이어갑니다. 검증을 위해 DB를 삭제하지 마세요. 새 설치는 전체 ZIP에서 install.bat 이후 실행.vbs를 사용합니다. Python 3.11 64bit 대상, 직접 시험은 3.12.14에서 했습니다. 트레이 추가 패키지는 없습니다.

## 검증용 초깃값
정책은 market_guard.py의 POLICY와 각 스캔/내보내기에 저장합니다. 아래 값은 기존 83개 거래를 최적화한 값이 아닙니다. 추가 검증 기간에는 고정해서 평가합니다.

| 상태 | 유효 후보 중 상승 추세 비율 | 신규 진입 |
|---|---|---|
| 약세 | 1/3 미만 | 차단 |
| 주의 | 1/3 이상, 1/2 미만 | 기존 금액 50%, 총 보유 최대 1종목 |
| 정상 | 1/2 이상, 회복 확인 통과 | 기존 주문금액·최대보유 설정 |
| 판정 불가 / 회복 확인 | 자료 부족·지연 / 새 완료봉 확인 중 | 차단 |

상승 추세는 완료 5분봉 종가 > SMA20 > SMA50입니다. BTC 단독으로 결정하지 않습니다. 후보군은 거래대금 상위 조회 종목이며 시장 전체를 대표하는 지수가 아닙니다. BTC는 표본에 포함될 수 있고 USDT/USDC/DAI는 표본에서 제외합니다.

- 전체 후보를 먼저 조회한 뒤 시장을 판단하고 신규 매수를 검토합니다.
- 유효 후보 최소 10개, 기대 후보 대비 커버리지 최소 80%가 필요합니다. 상위 조회 수 15개를 권장하며 10개 미만 설정 시 신규 진입이 잠깁니다.
- 표본 수신 후 45초 이내, 완료 캔들 시작 시각부터 300~660초인 자료만 사용합니다. 시장 평가가 90초 넘게 갱신되지 않으면 잠급니다. PC 시각 동기화가 필요합니다.
- 약세·판정 불가는 즉시 차단, 정상→주의는 즉시 축소합니다. 시작/재시작과 차단 후 재개 및 주의→정상 확대에는 서로 다른 완료 5분봉 구간의 같은 판정 2회가 필요합니다. 같은 캔들의 반복 조회는 확인 횟수를 올리지 않습니다. 보통 다음 5분봉 이후까지 기다립니다.
- 주의에서 이미 1종목 이상 보유하면 추가 진입을 하지 않습니다. 기존 보유는 강제 축소하지 않습니다. 축소 금액이 5,000원 미만이면 진입을 제외합니다.

## 급변 방어와 하루 손실 제한
기존 RSI 50~68·상승 추세·5분봉 +4% 이상 급등 제외에 추가:
- 완료 5분봉 종가 변화 -4% 이하 급락 제외.
- 완료 5분봉 (고가-저가)/전 봉 종가가 8% 이상이면 제외.
- 매수 직전 새 가격과 신호 완료봉 종가의 양방향 괴리 2% 이상이면 제외.
- 매수 직전 신호·시장 평가·통신·최대보유·당일 재매수 제한을 재확인합니다.

KST 날짜별 첫 유효 평가자산 대비 -2% 이하이면 그날 신규 진입을 잠급니다. 평가손익 포함이며, 가격 회복과 재시작 후에도 당일 잠금을 유지합니다. KST 다음 날짜의 첫 유효 평가에서 새 기준을 잡습니다. 장중 첫 실행이면 그 시점이 기준이며 과거 자정 자산을 복원하지 않습니다. 시세 부족일 때도 신규 진입을 잠급니다.

약세·판정 불가·일일 잠금 중에도 최신 시세가 있는 기존 보유의 손절·익절·트레일링은 계속 감시합니다. 이 기능은 신규 매수 제한이며 손실을 2% 또는 손절 3% 이내로 보장하거나 기존 보유를 일괄 청산하지 않습니다. 인터넷 단절 중 자동 청산은 불가능합니다.

## 기존 조건과 비교
첫 v1.8 실행 때 현재 가상 상태를 별도 benchmark_v18.sqlite3에 한 번 복사하고 이후 재시작에도 이어갑니다. 기존 v1.7 개별 진입 조건과 매매 설정으로 별도 가상매매를 관찰하며 새 시장·급락/진폭/괴리·일일 손실 제한을 비교 원장에는 적용하지 않습니다. 두 원장의 현금·보유·재매수 제한은 독립적입니다. 누락된 시세로 청산하지 않습니다.

가상 기록 화면에서 두 평가자산을 확인합니다. 내보내기에는 market_checks.csv, entry_decisions.csv, risk_days.csv, benchmark_v18.sqlite3, benchmark_trades.csv, benchmark_equity.csv, benchmark_summary.json이 추가됩니다. 기존 기록도 남습니다. entry_decisions는 허용 판단과 실제 체결 완료를 별도 행으로 저장하므로 전체 행 수를 매수 횟수로 세면 안 됩니다.

비교 원장은 공통 v1.8 전체 후보 조회 일정에서 관찰합니다. 과거 v1.7 실행 순서·시각을 완전히 재현하지 않으며, 가상 체결은 수수료 0.05%·편도 불리한 슬리피지 0.05%를 가정한 즉시 전량 체결입니다. 호가·부분체결·시장충격을 재현하지 않습니다. 정확한 v1.7 복제나 실거래 수익 비교로 해석하지 마세요.

## 트레이와 종료
- 주황색 비트코인 아이콘을 바탕화면·창·트레이에 사용합니다.
- 트레이 정상 등록 시 X는 숨김이며 매매 감시는 계속됩니다.
- 왼쪽 클릭은 창 열기. 우클릭은 창 열기 / 매매 중지·창 열기 / 프로그램 종료입니다.
- 종료 요청은 감시 작업이 끝난 뒤 창과 트레이를 종료합니다. 통신 요청 시간 제한만큼 기다릴 수 있습니다.
- 트레이 등록 실패 시 X는 중지 후 종료합니다. 숨김 상태에서 트레이 실패가 감지되면 창을 다시 표시합니다.
- 트레이 설명에 실행/중지와 시장 상태를 표시합니다. PC 절전이나 인터넷 단절을 방지하지는 않습니다.
