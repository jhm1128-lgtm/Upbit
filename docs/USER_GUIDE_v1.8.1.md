# v1.8.1 — 밝은 화면 · 시장 상태 표시 · 최소화 트레이

2026-10-30 제작한 v1.8용 화면 수정판입니다. 매매 정책 초깃값, 잔고·거래·보유·당일 제한·비교 원장은 이어갑니다. v1.8 실제 적용부터 진행 중인 약 1주일 관찰을 새로 시작할 필요는 없습니다. 업데이트 중 중단 시간만 별도로 기록하세요.

## 기존 v1.8에 적용
1. 중지를 누르고 감시 종료를 기다립니다.
2. 트레이 우클릭 → 프로그램 종료로 완전히 종료합니다. X는 숨김입니다.
3. validation.sqlite3, benchmark_v18.sqlite3, settings.json을 백업합니다.
4. Upbit_v1.8.1_UI_Update.zip 안의 파일을 C:\UpbitAutoTrading에 바로 풀고 덮어씁니다.
5. 기존 아이콘으로 실행해 v1.8.1 표시를 확인하고 시작합니다.

업데이트 ZIP에는 DB·설정·키·CSV를 넣지 않았습니다. v1.7에서 바로 적용하는 부분 패치가 아닙니다. 새 설치는 v1.8.1 Full ZIP을 사용합니다.

## 화면과 창 동작
- 밝은 청회색 배경과 읽기 쉬운 짙은 글자색. 시작·중지·주요 실행 버튼을 강조합니다.
- 매수후보는 메인화면으로 모았습니다. 전용 메뉴는 제거했습니다. 다른 메뉴의 이동과 후보 조회·차트 선택은 유지합니다.
- 보유종목 표는 약 5개 데이터 행, 손익 패널은 같은 높이로 표시합니다. 더 많은 항목은 스크롤/보유 메뉴에서 봅니다. 남는 높이는 위 매수후보·차트 영역이 사용합니다. 실제 보이는 행 수는 화면 배율·창 크기에 따라 달라집니다.
- 트레이 정상 등록 시 최소화 버튼과 X 모두 트레이로 숨깁니다. 감시는 계속됩니다. 트레이 클릭으로 다시 엽니다.
- 트레이 등록이 불가능한 환경에서 최소화는 작업표시줄을 사용하고, X는 중지 후 종료합니다. 완전 종료는 트레이 메뉴를 사용하세요.

## 큰 시장 상태 표시
| 화면 표시 | 내부 기록 state | 상태별 신규 진입 기준 |
|---|---|---|
| BULL · 상승 | normal | 기존 주문·최대보유 설정 |
| NORMAL · 중립/주의 | cautious | 주문금액 50%, 총 보유 최대 1종목 |
| BEAR · 약세 | bear | 신규 진입 차단 |
| WAIT · 판정 불가 | unknown | 신규 진입 대기 |
| RECOVERING · 회복 확인 | recovering | 새 완료봉 확인 중 대기 |

이름은 화면 표시용 대응입니다. 기존 v1.8 내부 state와 기준은 바꾸지 않았습니다. **화면 NORMAL은 내부 cautious**이며, 예전 안내에서 내부 normal이라고 부른 정상 진입 상태는 화면 BULL로 표시합니다. 후보군의 단기 완료 5분봉 추세를 요약하며 전체 시장의 장기 상승·하락이나 향후 수익을 예측하지 않습니다. BULL이어도 개별 신호·통신·당일 손실·보유 제한을 통과해야 신규 진입합니다.

기존 `상승 추세 14/14 (7.1%)` 표기는 앞 숫자가 자료의 유효 비율인데 상승 종목 수처럼 보이는 표시 결함이었습니다. 이제 **분석 가능 14/14 · 상승 1/14 (7.1%)**로 구분합니다. 판정 불가 상태에서는 과거 상승 비율을 계속 표시하지 않습니다.

## 수수료와 보유 수
누적 수수료는 기존처럼 양수 비용 합계로 표시합니다. 실현손익에는 매도 수량에 배분한 매수 수수료와 매도 수수료가 이미 반영돼 있으므로 누적 수수료를 다시 빼지 않습니다. 원장 계산은 바꾸지 않았습니다.

최대 보유 3→5는 아직 적용하지 않았습니다. 1회 15만원을 유지하면 최대 진입 원금은 45만원→75만원으로 늘어납니다. 이번 고정 설정 관찰을 마친 뒤 별도 조건으로 검토합니다. 주의 상태의 최대 1종목과 약세 진입 차단도 유지합니다. 10원 이하 제외는 이전 철회대로 적용하지 않았습니다.
